# Clarifier with Gradio Integration

__Options for Implementing Clarifier Agent__

1. Clarifier is an Accordian style section
- visible when "Clarifier" is clicked on Drop-down or Checkbox

2. Clarifier section contains 1 column with 3 rows
- becomes visible only when the Agent is called


__Pros & Cons__

Option #1 is probably the easiest to implement

It maintains a linear system with a more modular plugin

The system is optional


Option #2 involves a deeper integration with the current system

Research Topic --> Clarifier --> Questions Section --> Send Output to Manager Agent

It will require the User to do this every time
- maybe make a way to skip this (checkbox option to skip?)
